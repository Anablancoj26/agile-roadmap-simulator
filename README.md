## 🇬🇧 English

### 📌 Project Overview
An interactive web application designed to simulate agile project planning, task management via a Kanban board, and sprint roadmap visualization. Built to demonstrate the integration of Agile methodologies (Scrum/Kanban) with modern web software engineering.

### ✨ Key Features
- **Kanban Board:** Dynamic task management across workflow stages (*To Do*, *In Progress*, *Done*).
- **Agile Roadmap & Metrics:** Interactive sprint tracking and completion statistics.
- **RESTful API:** Clean backend architecture for task management.

### 🛠️ Tech Stack
- **Backend:** Python (FastAPI / Uvicorn)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Version Control:** Git & GitHub

## 🇪🇸 Español

### 📌 Descripción del Proyecto
Aplicación web interactiva diseñada para simular la planificación de proyectos ágiles, la gestión de tareas mediante un tablero Kanban y la visualización de roadmaps de sprints. Desarrollado para evidenciar la integración de metodologías ágiles (Scrum/Kanban) con la ingeniería de software moderna.

### ✨ Características Principales
- **Tablero Kanban:** Gestión dinámica de tareas a través de fases del flujo de trabajo (*Por Hacer*, *En Proceso*, *Completado*).
- **Roadmap y Métricas Ágiles:** Seguimiento interactivo de sprints y porcentaje de avance.
- **API RESTful:** Arquitectura backend limpia para la manipulación de recursos de tareas.

### 🛠️ Tecnologías Utilizadas
- **Backend:** Python (FastAPI / Uvicorn)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Control de Versiones:** Git & GitHub
